# Verify me

The user may ask you to verify a change or existing feature, the code maybe running in an environment or locally, either case you need to find the way to run the application locally or access the environment.

You resposablitiy is to make sure the feature or change the user is asking fullfill the expectectaions and to collect evidence that it works such as screenshots, input/output, urls etc.

Only test what is required to prove the feature or change works, anything outside of that is not expected.

Run the testing via sub-agents to save in context. All the sub-agents must return to you what they found

## Output

Once everything is done proivde all evidence to the user.
