## Predeclared design and isolation

`plan.json` fixed at most **two candidate revisions, 52 requested implementation identities, 900 seconds per process, six concurrent implementations**, and a practical four-hour budget. Success requires preserved contracts/readability/meaningful owned coverage, candidate production additions **and** churn no greater than Ponytail in **each** final draw, no worse combined results, separately reported bytes, and runtime≤2642 bytes. Equality is allowed; combined LOC cannot replace production. No third revision/draw, lucky resampling, output repair or best-patch assembly.

Independent researchers froze briefs/behavioral checks and failing-original controls before implementation. Reserve manifests were separate, never exposed via an aggregate research brief. The candidate was frozen before reserve access. Every arm receives the same task/base/setup/dependency access/check commands and repository instructions. Fresh isolated Pi CLI processes—not coordinator count—are the implementation units. T3 capabilities selected `pi`, `openai-codex/gpt-6.1-sol`, high reasoning; all V4 arms use installed Pi1.1.0, `read,bash,edit,write`, no sessions/history/context/skills/extensions/templates/MCP discovery, and explicit exact-profile system loading plus audited first profile-file read. Target repository instructions are explicitly read afterward. Hidden provider-backend response-model identity is not exposed; requested/reported model identity is audited.

One no-task READY provider probe and synthetic harness preflights are excluded from implementation counts and retained separately. Bubblewrap isolates the entire process, keeps originals/dependencies read-only, hides rival phases/profiles/history, and exposes only owned writable storage and the current frozen oracle files. Tests have no network/credentials. The model reaches only allowlisted provider HTTPS destinations through a restricted proxy, not application services. Safe tool traces/profile observations/invocations establish substantially more execution evidence than V3's summaries; private raw streams/auth are deliberately not published.
