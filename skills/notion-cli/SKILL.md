The CLI and API evolve, use the official docs https://developers.notion.com/cli/get-started/overview if you don't know how to do something or use the `ntn help` command. Do not invent endpoint paths, methods, flags, or JSON fields. Inspect the installed CLI for every operation:

There is a high level workspace called `Projects`, each child is a project like `matato-pi`, and each projects contains a `Research`, `Plans` and `Todos` pages.

**Research**: It stores all Research needed in a project.
**Plans**: All the ongoing plans for the project.
**Todos**: Ideas that are not explored.

When you create a new page under any of those categories you need to follow the templates, do not invest structure or be smart with it, follow consistency.
