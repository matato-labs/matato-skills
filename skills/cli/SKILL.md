# Project structure

The `Personal Work` workspace contains three databases:

- **Projects** tracks all projects. Plans are linked to projects.
- **Research** stores all research conducted by the user.
- **Plans** stores all ongoing plans for a project.

When you create a page in any of these databases, follow its template.
