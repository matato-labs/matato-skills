# Product

## Register

product

## Users

A private operator managing Pi coding-agent work across server-side projects, primarily from desktop with occasional mobile access.

## Product Purpose

Provide a secure remote Agent view for selecting a workspace project, starting or resuming Pi, following semantic conversation and tool activity, and controlling active work without exposing a terminal.

## Brand Personality

Focused, trustworthy, and quiet. Familiar productivity-tool density inspired by Linear, with the interface receding behind the work.

## Anti-references

Avoid terminal cosplay, dashboard card grids, decorative gradients, glass effects, excessive animation, and chat interfaces that hide tool state or execution status.

## Design Principles

- Make execution state unmistakable.
- Keep the conversation central and controls contextual.
- Reveal technical detail progressively.
- Prefer familiar controls over novel interaction patterns.
- Treat security and project boundaries as visible product behavior.

## Accessibility & Inclusion

Target WCAG AA, complete keyboard navigation, visible focus states, reduced-motion support, semantic status announcements, and state cues that do not rely on color alone.
