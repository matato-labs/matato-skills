# Design System

## Theme

A low-glare dark interface for an operator monitoring long-running agent work from a desktop in a dim home-office environment. Restrained color strategy with warm graphite surfaces and a single coral accent.

## Colors

Use OKLCH tokens. Base surfaces are warm graphite rather than pure black. Text is softly tinted off-white. Coral marks primary actions and ownership; green, amber, and red are reserved for semantic states.

## Typography

Use the native system sans stack for all UI and a native monospace stack for paths, commands, and tool output. Maintain compact product hierarchy and cap prose near 72ch.

## Layout

Desktop uses a narrow project/session rail and a flexible conversation pane. Mobile turns the rail into a top project selector. Keep the composer anchored beneath the transcript. Avoid nested cards.

## Components

Buttons, inputs, status indicators, message blocks, tool disclosures, and dialogs share consistent radii and focus rings. Tool details use native disclosure behavior. Loading uses message skeletons. Every status combines text with shape or icon.

## Motion

Use 150–200ms state transitions with ease-out curves. Disable nonessential transitions under reduced motion. No decorative entrance animation.
