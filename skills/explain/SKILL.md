name: explain
description: Use this skill when the user wants to fully understand something.
disable-model-invocation: true
---

Use Explain with `deep-dive` and `why`. Let those skills do the investigation. Use the results to give the user a gradual, comprehensive explanation. Build the explanation in small, clear steps. Address the user's request and follow these criteria.

1. Draw one or more Mermaid diagrams to show E2E workflow for the users question. Number the steps so the user can follow the sequence. Use the level of detail in the user's request.
2. Keep the explanation simple and direct. Avoid long, complex sentences.
3. Add evidence, code snapshots, sources or other material that helps the user understand `where` something happens.
