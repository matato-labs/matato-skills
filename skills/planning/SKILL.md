# Planning
Use this to draft the content of the plan, gather information and write the plan.

Find which project the user is asking you to create the plan for. Understand the users idea in comparison the current state of the project and try to find how it could be implemented, do not limit yourself the most obvious path, instead, ask the user for clarity when you have doubts, doing one questions, one at a time. Once the requirements and the project's current state are well Understand draft the content of the plan.

When creating writing the plan you need to specify the components that are affected, provide code samples, diagrams, charts or any tool that could help you to explain the plan.

## Follow ups
The user could ask you change things, to clarify points, etc. Keep what is ruled here at any moment when working in the plan in any exchange with the user.

## Out of scope
This skill doesn't specify how/where save the resulting planning.
