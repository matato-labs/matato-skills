# Handoff

Create a compact, meaningful summary of all work in the current session. Preserve objectives, changes, errors, and state. Do not omit important details that could be required to continue work in a new session.

Use verified information and facts to build the handoff. Do not invent events that did not happen in this session.

Write the output as the prompt for the next agent. Write it exactly as you would want to receive an initial prompt to start work.

> If `pbcopy`, `wl-copy`, or a similar tool is available on the system, copy the handoff to the clipboard.
